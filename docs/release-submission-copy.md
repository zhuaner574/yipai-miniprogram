# 一拍一拍发布填写材料

## 基本信息

### 小程序名称

一拍一拍

### 简介

记录每一次网球训练 比赛 心情与成长

### 功能介绍

一拍一拍是一款个人网球运动记录工具。用户可以记录训练或比赛日期 时长 心情和日记，在日历中查看打球频率，在成长页回顾历史记录与勋章，并获得与记录内容相匹配的鼓励回应。

### 服务内容说明

个人网球训练与比赛记录

不提供网球场地预订 教练交易 赛事报名 社区发帖 医疗建议或心理咨询服务

### 审核体验路径

首次进入 → 完成简单引导 → 首页 → 记录这一拍 → 填写训练信息 → 保存 → 查看日历和成长记录

应用不设置额外账号和密码，使用微信身份区分并隔离个人数据。

## 服务类目建议

优先在后台选择与个人记录工具最接近的工具类目。若后台提供以下方向，按实际可选项从上到下选择：

1. 工具 → 记录
2. 工具 → 效率
3. 体育 → 体育信息服务

不要选择带有场馆预订 赛事经营 健身课程交易或医疗健康服务含义的类目。

## 隐私保护指引填写依据

### 为实现核心功能处理的信息

- 微信用户标识：用于区分账号 隔离不同用户的数据
- 用户自行填写的昵称：用于页面内称呼
- 网球画像：包括当前水平 球龄 目标 持拍手 打球原因 练习方式 练球频率 常约球对象 比赛经历和当前困扰，用于完善个人记录与展示
- 打球记录：包括日期 时间 时长 打球方式和比赛结果，用于生成统计 日历和成长记录
- 心情 困扰和日记：用于保存个人回顾并匹配鼓励回应
- 用户反馈：用于发现产品问题并改进功能

### 不处理的信息

不申请或收集手机号 精确位置 通讯录 相册 麦克风 摄像头和身份证件信息。

### 数据使用范围

上述信息仅用于小程序内的个人记录 统计展示 内容回顾 鼓励回应和产品改进，不用于公开展示，不向其他普通用户开放。

### 数据存储与隔离

数据存放于微信云开发环境。数据库集合采用仅创建者可读写权限，不同微信账号之间的数据相互隔离。

### 用户控制方式

用户可以修改或删除单条打球记录，也可以在“我的”页面选择“删除我的全部数据”。全部删除需要经过两次确认，完成后清除该账号的个人资料 打球记录 日记 反馈和相关事件数据。

### 联系方式

请填写小程序主体可长期使用的真实邮箱或其他后台允许的联系方式：

`待填写：运营者联系邮箱`

## 版本审核备注

本小程序是个人网球运动记录工具。核心功能为记录训练和比赛 查看日历与统计 回顾成长记录。鼓励回应由本地规则语料匹配，不提供开放式人工智能问答，也不提供医疗或心理咨询服务。
