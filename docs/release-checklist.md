# 微信小程序接入与发布清单

## 需要用户提供

- 小程序 AppID
- 微信云开发环境 ID
- 小程序注册主体类型：个人 / 个体工商户 / 企业

AppID和云环境ID可用于项目配置，不是登录密码。不要发送 AppSecret、开发者私钥或验证码。

## 本地体验版

1. 在微信公众平台注册小程序。
2. 安装微信开发者工具。
3. 导入 `yipai-miniprogram` 项目目录。
4. 将 `project.config.json` 中的 `touristappid` 换成正式 AppID。
5. 编译并在模拟器完成新用户引导。
6. 点击“预览”，使用手机微信扫码真机体验。

## 云端接入

1. 在微信开发者工具中开通云开发。
2. 将环境 ID 写入 `config/env.js`。
3. 创建以下集合：
   - `profiles`
   - `sessions`
   - `feedback`
   - `events`
4. 将集合权限设为“仅创建者可读写”。
5. 上传并部署 `cloudfunctions/login` 和 `cloudfunctions/deleteAccountData`，选择“云端安装依赖”。
6. 真机验证新增记录、重新打开小程序、跨设备登录后的数据。
7. 使用测试账号验证“我的 → 删除我的全部数据”，确认四个集合只删除该账号的数据。

## 发布前产品检查

- 新用户可以完成引导并进入首页
- 不填写日记也能保存记录
- 比赛记录支持单轮比赛和多轮比赛，结果可选填
- 负面心情可以选择困扰关键词
- 保存后出现对应回复
- 首页按月统计正确
- 日历点亮正确
- 成长页可以展开历史回复
- 勋章解锁条件正确
- 反馈可以成功提交
- 用户可以通过二次确认删除自己的云端或本地数据

## 发布前合规检查

- 完成小程序备案
- 选择与实际功能一致的服务类目
- 配置微信用户隐私保护指引
- 解释昵称、训练记录、比赛结果、心情和日记的用途
- 不申请手机号、精确位置、通讯录等非必要权限
- 不将产品包装成开放式AI问答或心理咨询
- 填写运营者联系方式和数据删除渠道
- 页面中避免无授权的职业球员照片、赛事Logo和长段名言

## 审核材料

- 小程序名称：一拍一拍
- 简介：记录每一次网球训练、比赛、心情与成长
- 服务内容说明：个人网球运动记录工具
- 体验路径：新用户引导 → 首页 → 记录这一拍 → 保存 → 查看成长记录
- 审核账号：微信登录即可，不设置额外审核密码

## 首批体验发布

建议先生成体验版二维码，仅邀请10—20位真实球友：

- 3—5位刚开始学球的用户
- 3—5位有过比赛经历的用户
- 3—5位平时会写日记或做运动记录的用户
- 2—3位只愿意快速点击、不愿写长文字的用户

先验证记录是否轻松，再扩大公开分发。
